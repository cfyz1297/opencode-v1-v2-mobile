# OpenCode V1/V2 Mobile (форк cfyz1297)

**Русский** | [English](README.md)

> **Android-клиент для AI-агента OpenCode.** Управляйте сессиями `opencode serve` с телефона: живой транскрипт, подтверждение инструментов, диффы, смена модели и уровня рассуждений — по локальной сети, Tailscale или через туннель. Работает с **opencode 1.x (V1 API) и 2.x (V2 API)**, версия определяется автоматически.

Форк [dzianisv/opencode-mobile](https://github.com/dzianisv/opencode-mobile), собран на Expo/React Native. Распространяется только как APK из GitHub Releases — без магазинов, без аккаунта и без собственного бэкенда: приложение общается напрямую с вашим сервером.

Версия **0.3.25 (90)**, ставится поверх 0.3.24. Каждая сборка прогоняет 949 автотестов и Android CUA smoke на эмуляторе.

| Что нужно | Этот репозиторий |
|---|---|
| Android-клиент для **opencode 2.x** (`/api/*`) или **1.x** (`npm i -g opencode-ai`), один APK | да, автопереключение плюс ручной выбор |
| Клиент к серверу в **Termux** на том же телефоне, на ноутбуке или VPS | да — см. [opencode-termux](#android-сервер-в-termux) ниже |
| Подтверждения, диффы, стоп, сабагенты, вопросы — с телефона | да |
| Без телеметрии, аккаунта и Play Store | да — только APK из Releases |
| Сборка под iOS | нет — конфиг iOS удалён |

## Подключение к серверу opencode

Приложение говорит на обоих поколениях API: адрес опрашивается один раз, ответ запоминается для подключения, дальше используется подходящий транспорт — `/global/health` + `/global/event` для V1, `/api/info` + `/api/event` для V2. Определение идёт по телу ответа, а не по коду: неизвестный маршрут на обоих поколениях проваливается в веб-интерфейс и отвечает `200 text/html`. **Настройки → Сервер → API сервера** принудительно включает `v1` или `v2`.

### Ноутбук или VPS (V2)

```bash
curl -fsSL https://opencode.ai/v2/install | bash
OPENCODE_SERVER_PASSWORD=вашпароль opencode serve --hostname 0.0.0.0 --port 4096
```

Затем в приложении: **Add Connection** → `http://IP:4096`, логин `opencode`, пароль из команды.

### Android: сервер в Termux

Сервер для Android — [**opencode-termux**](https://github.com/cfyz1297/opencode-termux): OpenCode 2, собранный под Bionic, поэтому работает прямо в Termux без glibc, proot и слоёв совместимости. Именно такой сценарий и задуман: сервер и клиент на одном телефоне через `127.0.0.1` — поэтому разрешён cleartext к loopback и работает foreground-сервис для уведомлений.

```bash
curl -fsSL https://raw.githubusercontent.com/cfyz1297/opencode-termux/main/install.sh | bash
OPENCODE_SERVER_PASSWORD=вашпароль opencode serve --hostname 0.0.0.0 --port 4096
```

Обновление — `opencode upgrade` или повторный запуск установки. Сборки начиная с `2.2.5-r1` содержат исправление падения TUI на Android 17; API сервера тот же, что у официального бинарника V2.

### Серверы V1

Сервер opencode 1.x (`npm install -g opencode-ai`) донастройки не требует: тот же APK определит его и пойдёт через `/session`, `/session/{id}/prompt_async` и `/global/event`. Версии старше 1.18.x не поддерживаются.

## Что умеет приложение

- **Чат:** живой текст, рассуждения, инструменты и диффы в порядке модели; досылка сообщения во время прогона; стоп по реальному статусу сервера, поэтому прерывается и прогон, запущенный не с телефона; редактирование с откатом; саммари компакции; картинки.
- **Работа свёрнута на один ответ:** всё между двумя ответами — одна строка `5 · Оболочка, Чтение · 12.3s` с живым таймером, спиннером и крестиком при ошибке. Делегирование сабагента не сворачивается никогда.
- **Сабагенты:** строка внутри карточки, которая их запустила, с живым статусом и тапом в дочернюю сессию; два счётчика под шапкой (текущая пачка / всего за сессию); работающие сверху, готовые — новые первыми; дочерние сессии не попадают в список недавних.
- **Вопросы и подтверждения:** карточки на месте вопроса, после ответа свёрнуты в одну строку. Вопрос, пришедший пока приложение было закрыто, подхватывается при подключении — приложение забирает у сервера список активных сессий.
- **Длинные переписки:** навигатор над композером считает ваши сообщения и листает по одному; страница истории считается в запросах (5/10/25/50/Все); возврат в приложение сохраняет уже загруженное.
- **Информация о сессии:** кольцо контекста в шапке, токены, шкала контекста и трата за всю сессию.
- **Модели и агенты:** поиск по провайдерам, избранное, скрытые модели, уровень рассуждений там, где модель его отдаёт.
- **Подключения:** несколько серверов, пароли в Keystore/Keychain, честный статус «активно» (сервер ответил, опрос при фокусе и раз в 15 с), мастер туннелей Cloudflare и ngrok, экран провайдеров, отчёт диагностики.
- **Надёжность и приватность:** watchdog потока и перечитывание ленты после тишины, офлайн-история с шифрованием, биометрия, уведомления с фиксированным текстом, планшетная вёрстка, нативный keyboard inset, без телеметрии.

## Чем форк отличается от оригинала

Основа — [dzianisv/opencode-mobile](https://github.com/dzianisv/opencode-mobile) на `v0.4.15`; транспорт 1.x и фикс шапки из `v0.4.16`/`v0.4.17` перенесены вручную. Начиная с `v0.4.15` у форка своя линейка версий.

| Что | Оригинал | Этот форк |
|---|---|---|
| API сервера | только 1.x | **оба**, 1.x и 2.x, автопереключение |
| Доставка | Play, F-Droid, APK, EAS, iOS | только APK из GitHub Releases |
| Телеметрия | Sentry + PostHog | удалена |
| Ориентация / вёрстка | только портрет | любая; планшет от 768 dp |
| Офлайн-история | нет | шифрованная копия только для чтения |
| Туннели | только форма подключения | мастер Cloudflare и ngrok |
| Восстановление прогона | нет | watchdog тишины, перечитывание ленты, синхронизация активных сессий |
| Сабагенты | секция над лентой, только чтение | строка в карточке запуска, открывает дочернюю сессию; живой статус |
| Длинные переписки | плавающие кнопки поверх текста | навигатор над композером |
| Тесты | `node --test` по глобу | раннер + порог покрытия + CUA smoke на эмуляторе |

Главные части кода: `src/lib/v2-compat.ts` приводит ответы и события V2 к форме V1 (сторы и экраны общие), `src/lib/sdk-v1.ts` — транспорт V1, `src/lib/api-detect.ts` выбирает поколение, `src/lib/subagent-status.ts` строит строки сабагентов, `src/lib/tool-view.ts` рисует карточки инструментов, `src/lib/session-stats.ts` считает токены, контекст и цену для кольца и панели.

Чего нет: OAuth-подключения провайдеров (только ключ), OpenCode Cloud, сборок iOS, публикации в магазинах, телеметрии.

## Безопасность

- Пароли и офлайн-история лежат в Android Keystore / iOS Keychain с политикой `WHEN_UNLOCKED_THIS_DEVICE_ONLY`: они не попадают в резервные копии ОС и не восстанавливаются на другом устройстве.
- Простой `http://` не шифрует ни пароль, ни переписку; формы подключения об этом предупреждают. Для loopback (Termux на том же телефоне) предупреждения нет — трафик не покидает устройство.
- Приложение не запрашивает `SYSTEM_ALERT_WINDOW`, а уведомления о подтверждениях и вопросах несут фиксированный текст — никаких имён инструментов, путей и текста вопросов на экране блокировки.
- Телеметрии нет. Сборочные зависимости (Metro/Babel/Expo CLI) дают записи в `npm audit`; в APK этот код не попадает.

## Сборка и тесты

```bash
git clone https://github.com/cfyz1297/opencode-v1-v2-mobile
cd opencode-v1-v2-mobile
npm install
npm run android          # dev-сборка
```

Релизный APK собирает GitHub Actions на каждый пуш в `main` и на теги `v*`: сначала версии, typecheck и тесты, затем `expo prebuild` + `gradlew assembleRelease`, затем CUA smoke на эмуляторе Android. Гейты: `npm test`, `npm run typecheck`, `npm run test:coverage` (порог 80 %), `npm run check:versions` (сверяет и lockfile).
